## 🚀 Deployment (Frontend on Render)

### 1. Go to [Render](https://render.com)

### 2. Select **Static Site**

### 3. Connect Source Code

Connect your GitHub repository to Render.

### 4. Fill in the deployment fields:

| Field             | Value                   |
| ----------------- | ----------------------- |
| **Name**          | `bit-buddy` |
| **Project**       | `Bit Buddy`          |
| **Build Command** | `npm run build`         |
| **Branch**        | `production`            |
| **Publish Dir**   | `./dist`                |
